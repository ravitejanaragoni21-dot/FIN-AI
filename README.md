# FinPass AI (FIN-AI)

An AI-powered Financial Operating System & Credit Passport for SMBs and MSMEs in India.

## 🚀 Live Demo & Features
- **📊 Real-time Financial Dashboard**: Live KPIs for monthly revenue, net cash flow, cash reserves, and financial health score.
- **⚡ AI Risk Monitoring**: Early detection for cash flow shortages, overdue invoice alerts, and expense spikes.
- **💬 Multilingual Conversational Copilot**: Ask questions in English, Telugu, or Hindi, powered by Google Gemini AI.
- **💳 Business Financial Passport**: Instant credit readiness grading and exportable digital financial passport.
- **🧾 Smart Invoicing & Reminders**: Multilingual payment reminders via WhatsApp/SMS to accelerate collections.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Icons & Visuals**: Lucide Icons & Recharts
- **AI Integration**: Google Gemini 1.5 Flash API + Built-in Financial Reasoning Engine
- **Deployment**: Vercel

## 💻 Local Development
